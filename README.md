# ☕ Tratamento de Exceções em Java

Projeto desenvolvido durante meus estudos de **Java e Programação Orientada a Objetos**, acompanhando o curso **Java COMPLETO Programação Orientada a Objetos + Projetos**, do professor Nélio Alves.

O objetivo deste exercício foi praticar o tratamento de exceções em Java e compreender como organizar regras de negócio utilizando exceções personalizadas.

## 📚 Conceitos praticados

- Tratamento de exceções com `try` e `catch`
- Uso de `throw`
- Criação de exceções personalizadas
- Validação de regras de negócio
- Programação Orientada a Objetos
- Organização do código em classes e pacotes

## 🛠️ Tecnologias

- Java
- Eclipse IDE
- Git
- GitHub

## 🎯 Objetivo

Este repositório faz parte da minha jornada de estudos em **Java Back-end** e foi criado com finalidade educacional para consolidar conceitos de tratamento de exceções.
